如何添加自定义模型？
WhisperDock 支持 Hugging Face 仓库、直接检查点或本地模型目录。
  1. 1
    Hugging Face 微调模型
    在 Hugging Face 语音识别模型 中复制 owner/model-name 仓库 ID，例如 owner/whisper-finetuned-model；来源类型选「Hugging Face 仓库」，引擎使用 transformers。
  2. 2
    官方或自定义单文件检查点
    直接链接必须是完整 HTTPS 地址，且直接指向一个 .pt、.bin 或 .ckpt 文件；不要填模型网页、目录地址或 ZIP 压缩包。此类型使用 openai-whisper。
  3. 3
    导入本地模型
    本地 OpenAI 模型应为单个检查点文件；Transformers 模型应为包含 config 和权重文件的完整目录。导入后文件会复制进项目目录。
提示：添加模型前请确认磁盘空间和许可证。
